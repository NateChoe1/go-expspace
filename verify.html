This webpage simulates the asymmetric ko game and tries to verify that the gadgets described in this document correctly encode G3. Note that this page makes heavy use of unchecked Javascript evals, beware of XSS.

Initial G3 setup. The first line contains the initial value of X, the second line contains the initial value of Y, the third line contains F1 (the formula that X must follow after each move), the fourth line contains F2 (the formula that Y must follow after each move). Everything after that is ignored.
